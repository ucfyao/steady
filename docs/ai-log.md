# AI-assisted development log

I use Claude Code throughout. This log records where the AI's output was wrong or weak and how each problem was caught. It feeds the "AI tools" section of the README. New entries are added in the PR where the problem was found.

| 1   | Design note §7–8 (#1)              | The note promised a nickname and a "recovery code", and described trial storage as "~130 rows per session". The API design collects no personal data, offers no recovery, and stores a session's trials together with the session. | Re-reading the note against the API design before opening the PR                 | Reworded both sections to match the design                                                                                                                     |
| 2   | PR description (#1)                | The test plan said "all source links resolve" before anyone had checked.
